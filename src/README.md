# Структура программы

Консольная программа написана на языке программирования C++. Она состоит из двух основных структур: `DirectProblem` и `ReverseProblem`, являющихся наследниками структуры `Problem`. 

Их методы `input_ellipsoid` и `input_data` используются для ввода параметров эллипсоида и входных данных для задач.

Методы `output_result`, `output_header`, `output_row` используются для вывода результата выполнения программы в консоль.

Метод `solving_problem` осуществляет вызов остальных методов для решения задачи.

Основным же методом является `calc_problem` – в нем реализуется алгоритм для решения прямой или обратной задачи.

В программе реализованы два варианта для подсчета коэффициентов `A`, `B` и `C`: через экономизацию с отбрасыванием незначительных коэффициентов (метод `calc_coefficients_simplified`) и через экономизацию без отбрасывания коэффициентов (метод `calc_coefficients_standart`). 

Для хранения параметров задач реализованы структуры `DirectState` и `ReverseState`. В этих структурах хранятся входные и выходные значения, а также некоторые промежуточные вычисления. Для обратной задачи (в `ReverseState`) хранятся массивы с приближениями для некоторых промежуточных значений.

Для вывода используется `StreamSplitter`. Эта структура позволяет с помощью одного объекта выводить и в консоль, и в файл. Пример использования:

```cpp
StreamSplitter out;
std::string filename;
std::cout << "Введите название файла: ";
std::cin >> filename;
out.enableFileLogging(filename);
out << "Вывод и в консоль, и в файл." << std::endl;
out << StreamType::FileOnly << " Вывод только в файл " << std::endl;
out << StreamType::ConsoleOnly << " Вывод только в консоль " << std::endl;
out << StreamType::Both << "Снова вывод и в консоль, и в файл" << std::endl;
```

Структура `PointPrinter` нужна для вывода широты, долготы и азимута точек. Пример использования:

```cpp
Point point1{0, 0, 0};
out << PointPrinter(point1, 1, true) << std::endl;
```

Конструктор имеет вид: `PointPrinter(const Point& p, int ind = 1, bool show_rad = false)`, где `p` – точка, которую хотим вывести, `ind` – ее индекс (будет использован как значение рядом с широтой, долготой и азимутом) и `show_rad` – нужно ли выводить значения широты, долготы и азимута в радианах.

В программе также реализованы некоторые вспомогательные примитивные структуры (для точек, эллипсоида, углов и коэффициентов `A`, `B` и `C`).

# Использование программы

В программе поддерживаются следующие команды:
* `\help` – вывод доступных команд
* `\direct` – режим для решения прямой задачи
* `\reverse` – режим для решения обратной задачи
* `\quit` – выход из программы

Рассмотрим подробнее работу с режимами для решения прямой и обратной задач.

## Формат ввода

Для ввода вещественных чисел следует использовать в качестве разделителя целой и дробной части точку.

Ввод углов имеет следующий формат:  
`ГРАДУСЫ МИНУТЫ СЕКУНДЫ`

При выборе любого из режимов (то есть при вводе команды `\direct` или `\reverse`) пользователю будет предложено сохранить результат работы программы в файл. Чтобы сохранить результат необходимо сначала ввести символ `y` (согласиться на сохранение), а на следующей строке ввести имя файла, в который будут сохранены данные. Если результат сохранять не требуется следует ввести символ `n`.

Далее пользователю будет предложено ввести параметры эллипсоида. К ним относятся малая полуось эллипсоида `b` (в метрах), квадрат эксцентриситета `e²` и квадрат второго эксцентриситета `e'²`. 

Вопрос о сохранении результатов в файл и ввод параметров эллипсоида будут предложены пользователю при каждом вызове команды `\direct` или `\reverse`.

Далее происходит ввод входных значений для задач.

## Прямая задача

**Входные данные:**
1. Широта `B1` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в начальной точке геодезической линии
2. Долгота `L1` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в начальной точке геодезической линии
3. Азимут `A1` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в начальной точке геодезической линии
4. Длина геодезической линии `s` (метры)

Далее пользователю предлагается выбрать способ подсчета коэффициентов (необходимо ввести цифру 0 или 1):
* `0` - через экономизацию с отбрасыванием незначительных коэффициентов
* `1` - через экономизацию без отбрасывания коэффициентов

## Обратная задача

**Входные данные:**
1. Широта `B1` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в начальной точке геодезической линии
2. Широта `B2` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в конечной точке геодезической линии
3. Долгота `L1` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в начальной точке геодезической линии
4. Долгота `L2` (ГРАДУСЫ МИНУТЫ СЕКУНДЫ) в конечной точке геодезической линии

Далее пользователю так же, как и в прямой задаче, предлагается выбрать способ подсчета коэффициентов (необходимо ввести цифру 0 или 1).

## Вывод программы

Программа выводит в консоль (и сохраняет в файл, если это было необходимо) промежуточные значения, в том числе приближения, и выходные значения для задач.
